# Generators

- `seed_generator.py`: create and deduplicate scene seed pools.
- `oral_text_generator.py`: generate spoken-form transcripts with scene-specific phenomena.
- `clean_text_generator.py`: transform Oral text into written-form targets.
- `asr_simulator.py`: produce aligned ASR-style input text through LLM, text, or TTS/ASR simulation.
- `__init__.py`: package marker.
