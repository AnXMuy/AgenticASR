# Configuration

- `settings.py`: environment variables, scene ratios, service URLs, data paths, and generation defaults.
- `scenes.py`: scene registry and per-scene language/noise metadata.
- `prompts.json`: seed-generation prompts.
- `prompts_oral.json`: Oral transcript prompts.
- `prompts_clean.json`: Clean transcript prompts.
- `__init__.py`: package marker.
